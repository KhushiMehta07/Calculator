# 🧮 Qt Calculator

A modern desktop calculator application developed using **C++ and Qt Framework**.
The application provides a clean graphical user interface for performing basic arithmetic operations.

## ✨ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Clear (`C`) functionality
- Numeric keypad
- Expression display
- Result display
- Dark-themed user interface
- Interactive GUI
- Event-driven button handling using Qt Signals & Slots

## 🖥️ User Interface

The calculator features a simple and modern dark-themed interface with:

- Large display area for expressions and results
- Number buttons from `0` to `9`
- Arithmetic operation buttons
- Clear button
- Equal button

### Example

```text
10 + 10 = 20
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/KhushiMehta07/Calculator.git
```

### 2. Open the Project

Open the cloned project in Qt Creator.
Open: `CMakeLists.txt`

### 3. Configure the Project

Select a suitable Qt Kit and C++ compiler when prompted by Qt Creator.

### 4. Build the Project

Use: **Build → Build Project**
or press: `Ctrl + B`

### 5. Run the Application

Click the **Run ▶** button in Qt Creator.
