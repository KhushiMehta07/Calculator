# 🧮 Qt Calculator

A simple desktop calculator built with **C++ and Qt**.

## Features
- Add, Subtract, Multiply, Divide
- Clear (`C`) button
- Numeric keypad
- Dark-themed UI

## Tech Used
C++ • Qt 6 • Qt Designer • CMake

## Getting Started
```bash
git clone https://github.com/KhushiMehta07/Calculator.git
```
1. Open `CMakeLists.txt` in Qt Creator
2. Select your Qt Kit
3. Build (`Ctrl + B`)
4. Run ▶
